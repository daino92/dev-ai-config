# Coding Guidelines

Write production-quality code that is easy to understand, test, and maintain.

- Prefer clarity over cleverness.
- Keep functions focused and names descriptive.
- Avoid hidden side effects.
- Handle failure paths explicitly.
- Remove dead code instead of commenting it out.
- Keep dependencies minimal.
- Separate server state, client state, URL state, and derived state.
- Avoid storing derived values in state.
- Respect semantic HTML and keyboard navigation.
- Preserve responsive behavior.
