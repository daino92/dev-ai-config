# React Skill

- Prefer function components and hooks.
- Keep state as local as practical.
- Do not use effects for values that can be derived during render.
- Use effects for synchronization with external systems and clean them up explicitly.
- Prefer composition over oversized configurable components.
- Use stable domain keys.
- Avoid unnecessary memoization.
- Keep deeply presentational components independent from data fetching where practical.
- Treat loading, empty, error, and success states deliberately.
- Maintain accessible labels, focus behavior, semantics, and keyboard interaction.
